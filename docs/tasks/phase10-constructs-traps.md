## Design (proposed)
- **Construct OnTick/OnInterval.** `Construct.Interval` (0.1–10 s, optional). When set, the Construct runs OnTick every Interval while active. Targets: Humanoids inside its Proximity radius when it has Proximity settings, otherwise the attached character (or none) — a turret uses SpawnEffect (Projectile) or Explode on OnTick. Payload/behavior timing tables gain Construct OnTick/OnInterval.
- **Construct.Health (optional, 10–`MaxConstructHealth` 500).**
  - Pure `MagicConstructHealthSpec` (apply damage, destroyed at 0, clamps, restore value) + thin server `MagicConstructHealth` table keyed by the construct record (persistent Constructs get a lightweight record); model attributes `MagicConstructHealth`/`MagicConstructMaxHealth` replicate for a future health bar.
  - What damages it: spell Damage payloads whose impact `HitPart` is one of its parts (flat Amount × potency; ScaleBy not applied to structures), and player melee hitboxes that overlap its parts. The caster's own spells never damage it; another player only when CombatPolicy lets them fight its owner (PvP caps apply via `Caps.damage`); NPC-owned spells always. Enemy AI does not target structures (out of scope).
  - At 0: `OnDestroyed` fires at the construct's position (targets: whoever dealt the final hit, if eligible), then it is removed **without** OnExpire.
  - Persistent Constructs: saved records gain optional `Health`/`MaxHealth` (spec stays Version 1; fields optional). Damage updates the saved value, debounced (≤ 1 DataStore write per record per 30 s, plus one on destruction via the existing removal path). Restore rebuilds with the saved health. They have no triggers (only visuals are saved), so no OnDestroyed there.
- **Field traps.**
  - `ArmDelay` (0–10 s): OnEnter/OnExit/OnTick/OnInterval/OnProximity are ignored until armed; anyone inside when it arms counts as entering then. OnCast/OnSpawn are unchanged.
  - `ConsumeOnTrigger`: the first OnEnter with at least one target (after arming) runs, then the Field ends (OnExpire runs as usual).
  - `Hidden`: the server makes no marker Part (nothing replicates). `MagicPresentation` sends the marker description over its remote only to players who cannot fight the caster (owner, allies, anyone outside PvP); a new client `MagicHiddenMarkerController` draws it locally and removes it on end. Recipients are re-checked every second (zone/duel changes add or remove it). No ambient loop sound for hidden traps. Validation: Hidden rejects FollowTarget and growth (the local marker is static). A trap is revealed by its own effects when it triggers.
- **PvP caps** (provisional): `MaxConstructHealth` 150 open / 100 ranked (no unbreakable walls in PvP; applied at cast by the caster's zone, like Rush); `MinHiddenTrapArmDelay` 1 s open / 1.5 s ranked; structure damage uses the existing `DamageMultiplier`/`MaxDamagePerHit`.
- MagicLab (provisional): `MaxConstructHealth = 500`, `MaxConstructInterval = 10`, `MaxTrapArmDelay = 10`, `PersistentHealthSaveInterval = 30`.
