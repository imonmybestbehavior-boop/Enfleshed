# Grimoire notebook artwork

The generated open-notebook image is [`assets/ui/grimoire_open_notebook.png`](../assets/ui/grimoire_open_notebook.png). The grimoire uses it as an `ImageLabel` behind the interface.

The PNG was uploaded under the `enfleshedgame` Roblox account. Roblox assigned decal ID `103709786302797` and generated **image ID `90191098757743`**. [`src/client/UI/GrimoireArt.luau`](../src/client/UI/GrimoireArt.luau) uses `rbxassetid://90191098757743` for the `ImageLabel`.

The light paper background remains as a fallback if the image cannot load. The asset may need permission for a different Roblox creator account or group that owns the published experience.
